# bo-sintetic-data

## Descrição

Este repositório contém **dados sintéticos de relatos de Boletim de Ocorrência (BO)**, gerados artificialmente com o auxílio de modelos de linguagem (LLMs) por meio de APIs de inteligência artificial.

Os dados **não representam eventos reais** e foram criados exclusivamente para fins de pesquisa, desenvolvimento e treinamento de modelos de aprendizado de máquina.

## Geração dos Dados

Os relatos sintéticos foram gerados utilizando as seguintes APIs e modelos:

| Provedor | Modelo |
|----------|--------|
| OpenAI   | `gpt-4o-mini` |
| Google   | `gemini-2.5-flash` |

## Aviso

> ⚠️ **Atenção:** Todos os dados contidos neste repositório são **sintéticos** e foram gerados artificialmente. Qualquer semelhança com situações ou pessoas reais é mera coincidência.
